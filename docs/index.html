東京23区の限定みやげ

7か所 ・ 17品東京駅の改札内「グランスタ東京」は、駅限定品がいちばん集まる場所です。浅草・人形町・銀座には、その店でしか買えない老舗の和菓子や専門店のお菓子があります。

大阪の限定みやげ

7か所 ・ 14品梅田の百貨店（阪急・阪神・大丸）は新しい限定スイーツの集まる場所、なんばは焼きたての定番、新大阪駅は帰り際にまとめて買える場所です。

「限定」の種類について

この店・この駅だけ 特定の店舗・駅・百貨店でしか買えない品。
地域限定 その地域（大阪府内・関西など）の店でしか買えない品。
地元の名物 通販や他地域でも手に入ることがあるが、その土地らしい定番の品。

価格・販売状況は各ページの「最終確認日」時点の情報です。限定品は販売終了や価格改定が多いので、出かける前に各店の公式情報を確認してください。
