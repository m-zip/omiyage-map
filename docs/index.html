東京23区の限定みやげ

16か所 ・ 28品東京駅の改札内「グランスタ東京」と羽田空港は、駅・空港限定品が集まる場所です。新宿・渋谷・池袋のデパ地下には店舗限定のお菓子があり、浅草・上野・人形町・銀座には、その店でしか買えない老舗の和菓子があります。

大阪の限定みやげ

10か所 ・ 20品梅田と天王寺の百貨店（阪急・阪神・大丸・あべのハルカス近鉄）は新しい限定スイーツ、なんば・新世界・住吉は老舗の名物、新大阪駅は帰り際にまとめて買える場所です。

    「限定」の種類について

    この店・この駅だけ 特定の店舗・駅・百貨店でしか買えない品。
    地域限定 その地域（大阪府内・関西など）の店でしか買えない品。
    地元の名物 通販や他地域でも手に入ることがあるが、その土地らしい定番の品。
